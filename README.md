# Uday Arya — Portfolio

Cyberpunk personal site for employers. About copy, experience, and skills come from [LinkedIn](https://www.linkedin.com/in/uday-arya-b15644245/). Projects load live from [GitHub](https://github.com/Uday-Arya), using each public repo's `README.md` as the description.

## Local development

```bash
npm install
npm run dev
```

## Free hosting (GitHub Pages)

1. Create a GitHub repo named `uday-arya-portfolio` under `Uday-Arya`.
2. Push this project to `main`.
3. In the repo: **Settings → Pages → Source → GitHub Actions**.
4. Site URL: `https://uday-arya.github.io/uday-arya-portfolio/`

The deploy workflow builds a static site and publishes it at no cost.
